关于 STERN IP

埃及、中东和非洲最高效的知识产权事务所之一。

专业从事商标、专利和工业设计注册及一切相关服务的专利代理人。

01关于我们

中东和北非地区知识产权注册与保护的先行者。

我们负责专利、设计和商标的年费缴纳与续展，以及在埃及注册的本地和国际商标的转让申请、许可合同、异议和请愿——并提供一切相关服务。

STERN IP LTD 是埃及专利代理人组织成员，凭借市场覆盖面、广泛的知识产权服务和专业团队，被视为中东和北非地区最大的知识产权事务所之一。我们通过开罗办事处及全球50家代理机构提供服务。

我们于2008年在开罗成立，恪守高标准的职业道德与专业规范，依托合格的内部专业团队和先进技术，为客户提供量身定制的全方位知识产权服务。

02我们的历程

始于2008年。

  1. 2006

    创始人在律师公会注册为律师。

  2. 2008

    STERN IP LTD 在开罗成立，并在贸易部注册为商标和专利代理人。

  3. 2015

    荣获埃及最佳知识产权律所。

  4. 2018

    协助商标局更新埃及知识产权法。

  5. 2019

    再次荣获埃及最佳知识产权律所，并被 Managing Intellectual Property 评为埃及五大知识产权律所之一。

  6. 今天

    在阿拉伯世界和非洲设有11个办事处，在全球拥有50家联络及代理机构。
