# Cookies Café — كوكيز كافيه

Static one-page site (Arabic, RTL). No build step: upload this folder as-is to any static/PHP host.

- `index.html` — page
- `assets/css` — styles + self-hosted fonts (Baloo Bhaijaan 2, Tajawal, Pacifico, Fredoka)
- `assets/js/menu-data.js` — **menu items and prices** (edit here), mood picker
- `assets/js/app.js` — animations (GSAP + ScrollTrigger + Lenis), cart, WhatsApp/email ordering, reservations
- `assets/frames/` — 79-frame milkshake sequence scrubbed on scroll (generated with Higgsfield)
- `assets/img/` — product photos + mascot cutouts (generated with Higgsfield from the client logo)
- `_source/` — the original logo and printed menu from the client (not used by the page)

Orders and reservations open WhatsApp (wa.me/201203101104) with a prefilled message, or email info@theplanetco.com.
